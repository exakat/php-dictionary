# Markup
Markup is a way to write text with annotations that describe its structure or its presentation. The annotations are either tags, such as ``<h1>`` in HTML, or lightweight symbols, such as ``#`` in Markdown.

Markup separates the content from how it is displayed. The same source can be rendered as a web page, a PDF, or plain text.

Typst is a markup language for typesetting. It mixes markup for text with a scripting language for logic, and it compiles documents to PDF. It is a modern alternative to LaTeX, with a faster compile time and simpler syntax. A PHP extension gives access to the Typst engine.
