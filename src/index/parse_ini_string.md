# parse\_ini\_string()
``parse_ini_string()`` parses a string formatted like a PHP ini file, and returns its settings as an associative array, the same way ``parse_ini_file()`` does for a file on disk.

Values are read as plain strings by default, sections become nested arrays when the second argument is true, and passing ``INI_SCANNER_TYPED`` as the third argument converts recognisable booleans, integers and floats to their matching PHP type instead of leaving every value as a string. ``INI_SCANNER_RAW`` disables all value processing, including the quote stripping that happens by default, and returns each value exactly as written.

Because the parser follows the same rules PHP itself uses for its own configuration files, an ini string built dynamically, from a template or generated by another script, can be validated before being written to disk, simply by parsing it back and checking the result.
