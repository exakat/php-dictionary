# Rector
Rector is a PHP refactoring tool that automates code upgrades and migrations.

Rector is able to:

+ Upgrade PHP code to newer PHP versions
+ Apply coding standards automatically
+ Refactor code patterns
+ Migrate between frameworks
+ Apply custom rules.
