# Information Retrieval
Information retrieval is the science of finding documents or records that match a user's need. It is the basis of search engines, and it relies on building an index, scoring matches, and ranking results.

The core steps are tokenizing text, building an inverted index that maps each term to the documents containing it, and ranking the results with a score such as TF-IDF or BM25.

A PHP extension can provide these primitives directly, which is faster than doing the same work with explicit PHP syntax.
