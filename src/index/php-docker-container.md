# PHP Docker Container
This is a Docker container, with a pre-installed PHP executable. 

There are official PHP containers, maintained by the PHP group. They are to be run on Docker.

There are also other containers which come with PHP preinstalled, or which are built for a specific target, such as a service or the underlying architecture.
