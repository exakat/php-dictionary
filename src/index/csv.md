# Comma Separated Values (CSV)
CSV is a data format, where values are separated by commas. 

Each line represents a data record. The first line may be a header line, or not. 

CSV is not fully standardized: it represents in fact several formats, with different features. In particular, nested new lines and escape sequences may vary from format to format.
