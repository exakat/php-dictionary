# End of Life (EOL)
End of life, or EOL, is the date after which a software version no longer receives updates, including security fixes. Each version of PHP, a framework or a library has a support window: it is supported with bug and security fixes for a fixed period, then it reaches end of life and is left as it is.

Running an EOL version is a security risk, since any vulnerability found after the EOL date will not be patched. Libraries and frameworks usually ship a support table, and it is worth checking it before upgrading or deploying, since an application on an EOL runtime is harder to get patched and may stop receiving compatibility updates from its dependencies.

EOL is not the same as deprecation. A deprecated feature is still supported but flagged for removal, while an EOL version has stopped receiving any updates at all. A deprecation usually comes first, and the EOL date is what ends the support window for the whole release.
