# Archive
An archive is a single document that stores a collection of files and directories.

There is PHAR, ``PHP Archives``, which contains PHP code, and any other kind of file, and can be executed directly.

There are also other archive formats, such as TAR, for files or JAR, for Java applications, etc.

An archive is often an artefact of compression, using ``Zip``, ``Rar`` or ``Tar``.
