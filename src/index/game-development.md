# Game Development
Game development is the practice of building interactive software for players. It covers the game loop, rendering, input, audio, physics, networking, and integration with platform services such as achievements, leaderboards, and matchmaking.

PHP is rarely used for games, but it can drive server-side game logic, tools, and platform services. Bindings to platform SDKs let a PHP program use those services directly.

Steamworks is the SDK of Valve's Steam platform. It gives access to achievements, stats, cloud saves, and the rest of the Steam services.
