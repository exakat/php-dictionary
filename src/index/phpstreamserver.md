# PHPStreamServer
PHPStreamServer is an event-loop-based application server and process supervisor built entirely in PHP, on top of the Revolt event loop and the AMPHP ecosystem. Instead of the traditional PHP-FPM model, where every request boots a fresh process and discards its state, PHPStreamServer runs long-lived worker processes that keep the application booted between requests, similar in spirit to Swoole or RoadRunner but implemented purely in userland PHP with no external binary or extension required. Beyond serving HTTP requests, it also supervises worker processes, restarting them automatically on failure, and bundles a built-in task scheduler, letting a single tool replace the usual combination of Nginx, PHP-FPM, Cron, and Supervisor for a self-contained deployment. This approach trades some of the raw throughput of a compiled runtime for easier installation and a codebase developers can read and extend in plain PHP, targeting teams that want async, persistent-state performance benefits without adopting a C extension like Swoole.
