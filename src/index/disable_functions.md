# disable\_functions
The ``disable_functions`` PHP directive prevents specific native functions from being called by the code. It takes a comma-separated list of function names, such as ``exec, shell_exec, system, passthru, popen``, and makes those functions unavailable at runtime, even when they are compiled into PHP.

This directive can only be set in the ``php.ini`` file, a virtual host configuration, or the server configuration: it is read at startup and cannot be changed with ``ini_set()`` in the code. A script that tries to call a disabled function gets a fatal error, and the function appears as undefined.

``disable_functions`` only works on native functions and extension functions. It cannot disable a custom function: this can be achieved by defining the forbidden function in the code and making it emit a warning or do nothing. A disabled function may also be redefined as a custom function, which is why it is not a complete protection on its own.
