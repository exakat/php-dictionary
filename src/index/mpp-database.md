# Massively Parallel Processing Database (MPP)
A massively parallel processing database, or MPP database, is a database architecture where a query is split into fragments and executed simultaneously across many independent nodes, each with its own CPU, memory and storage.

This shared-nothing design contrasts with a single-server database: instead of one machine reading every row, the data is partitioned ahead of time across the nodes, and each node scans and processes only its own share, before the partial results are combined into the final answer.

MPP architectures are common in analytical, OLAP-style workloads, such as data warehouses, where a handful of queries scan billions of rows, rather than transactional, OLTP-style workloads, made of many small reads and writes. Amazon Redshift, Google BigQuery and Vertica are widely used MPP databases; PHP applications typically reach them through a standard SQL driver, the same way they would connect to a regular relational database.
