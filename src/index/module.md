# Module
In computer science, a module, providing modularity, refers to a self-contained unit of code or software that encapsulates a specific functionality or set of related functionalities. It is a fundamental concept in modular programming, which aims to break down complex systems into smaller, more manageable components.

A module is also a standardized package, that can be replaced or plugged into a system with a common interface.

In the PHP world, modules often refer to specific frameworks' components: for example, Drupal and Laravel use modules to extend their features.
