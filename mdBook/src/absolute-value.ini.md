# Absolute Value
An ``absolute`` value is the positive value of a real number.

PHP offers the native function ``abs()`` to calculate this value.

The absolute value of ``PHP_INT_MIN`` is a float.

```php
<?php

    $a = 10;
    echo abs($a); // 10
    
    $b = -12;
    echo abs($b); // 12

?>
```
