# var_dump()
``var_dump()`` displays the information in a variable or any data container. It is a debugging function.

``var_dump()`` is one of the most famous PHP function. It is often related to ``print_r()`` and ``var_export()``. 
```php
<?php

    $a = true;
    var_dump($a);
    // bool(true)

?>
```
