# Wrapper
A wrapper may be two things: 

+ PHP wrapper, a built-in tool to process various URL-style protocols
+ Design pattern, also known as adaptor.
```php
<?php

// the PHP wrapper http
$html = file_get_content('http://www.php.net/');

?>
```
