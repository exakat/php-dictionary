# Indexed Array
An indexed array is an array whose keys are only integers. The keys may be explicit or implicit.

An array with string index is an associative array.
```php
<?php

$associative = [10 => 'a', 'b'];

echo $associative[10]; // a
echo $associative[0]; // b

?>
```
