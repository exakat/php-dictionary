# Data Container
A data container is a structure that stores data. It is a generic concept, that covers variables, both local and global, properties, both static and simple, and array elements.
```php
<?php

    $a = 1;
    $object->property = 'b';
    $array = ['a', 3, 4.4];

?>
```
