# .htaccess

The .htaccess file is a configuration file used in web servers that support the Apache HTTP Server software. It allows the configuration of various aspects of how your web server operates and how it serves web content. The name ``htaccess`` stands for ``hypertext access``, and the file is often referred to as an ``htaccess file``.
