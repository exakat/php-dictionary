# Positive Integer

A positive integer is an integer value which is 0 or larger. 

PHP handles only signed integers, and there are no specific types to characterize positive integers.

Some functions return only positive integers, such as ``abs()``, ``strlen()`` or ``count()``. Yet, they are typed with a return type of ``int``.
