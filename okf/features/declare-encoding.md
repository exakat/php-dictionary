# declare Encoding

``declare()`` with the ``encoding`` keyword specifies the encoding of the file that holds PHP script. This applies to the current file only. It affects both syntax, that PHP processes, and the literal values, which are ultimately displayed.

```php
<?php

    declare(encoding='UTF-8');

?>
```
