# Browser

A browser, short for web browser and also called a navigator, is a software application designed to access, retrieve, and display content from the World Wide Web. It allows users to view and interact with websites, web applications, and online services.

PHP features ``get_browser()`` native function, which lists some of the requesting browser capabilities.

PHP acts as a http client rather than a browser, when using the ``http://`` wrappers, the curl extension or the components like ``guzzle``, ``amphp``, ``reactphp``, etc.
