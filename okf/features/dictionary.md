# Dictionary

A dictionary is a data structure that holds a collection of values with a unique identifier. Each identifier is an integer or a string and may be other types in rarer occasions. The related values may be of any type. 

A dictionary structure relies often on the array data structure.

```php
<?php

$dictionary = ['a' => 'blue',
               'b' => 'pink',
               'c' => ['green', 'yellow'],
              ];

?>
```
