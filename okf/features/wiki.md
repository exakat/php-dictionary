# Wiki

A wiki is a web application that lets users create, edit and link pages collaboratively, directly from the browser, without needing a separate publishing workflow.

A wiki keeps a full revision history of every page, so any edit can be reviewed, compared to previous versions or reverted. Pages are usually written in a lightweight markup syntax and interlinked by name, which lets a body of documentation grow organically as new pages are referenced before they even exist.

The PHP ecosystem offers a lot of wiki engines. Here is a non-exhaustive list:

+ ``MediaWiki``, which powers Wikipedia
+ ``DokuWiki``, file-based, no database required
+ ``PmWiki``, file-based, no database required
+ ``Tiki Wiki CMS Groupware``
+ ``BookStack``
+ ``XWiki``.
